Besoins

  • US03 : route guards (auth + rôle), navigation filtrée, aucun lien vers une action interdite.
  • US04 : rôle courant affiché ; « Mes événements » visible uniquement pour ORGANIZER.
  • US02 : restauration de session par un seul appel GET /me (A3) au chargement.
  • 401 global → login ; 403 → message dédié.
  • Le front se base sur code, jamais sur message.

Points ouverts

  • Mécanisme d'attribution d'ORGANIZER (contrat §10, point 6).
  • Le back renvoie des erreurs RFC 9457 (errors[]) au lieu de error.details du contrat §5 : à aligner dans le client API.
