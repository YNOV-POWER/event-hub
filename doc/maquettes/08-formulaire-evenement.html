Besoins · US05 (SCRUM-31)

  • Validation client : titre 3–120, lieu 1–200, début dans le futur, fin > début, capacité ≥ 1.
  • Erreurs serveur affichées par champ.
  • Dates saisies en heure locale, envoyées en ISO 8601 UTC.
  • Succès 201 → retour à « Mes événements ».

US07 (SCRUM-35)

  • Formulaire prérempli depuis GET /events/{id}.
  • Erreur R6 (409 CAPACITY_BELOW_CONFIRMED) affichée clairement.
  • Édition désactivée si CANCELLED.

API

  • POST /events (E4)
  • GET /events/{id} (E2) + PATCH /events/{id} (E5)
