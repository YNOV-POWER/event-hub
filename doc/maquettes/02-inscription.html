Besoins · US01 (SCRUM-23)

  • Champs : email, password, displayName. Pas de champ rôle.
  • Validation client : mot de passe ≥ 12 caractères, displayName 2 à 80.
  • Erreurs serveur affichées par champ (field).
  • Message dédié pour 409 EMAIL_ALREADY_USED.
  • Succès 201 → redirection vers la connexion avec bandeau « Compte créé ».

API

  • Action : POST /auth/register (A1)
