Besoins · US02 (SCRUM-25)

  • Formulaire de connexion ; bouton désactivé pendant la requête.
  • 401 INVALID_CREDENTIALS : message générique (pas d'indication email/mot de passe).
  • Jeton envoyé en Authorization: Bearer sur les appels protégés.
  • Stockage du jeton à décider avec le back et documenter (risque XSS, US17).
  • Après succès : retour à la page d'origine, sinon catalogue.
  • Déconnexion depuis l'en-tête (suppression du jeton).

API

  • Action : POST /auth/login (A2) ; la réponse contient user, pas besoin d'appeler /me.
  • Rechargement de page : GET /me (A3) uniquement.
